# Персональная веб-страница «О себе»

Учебный проект (Вариант 1: Студент-разработчик) — цифровая визитная карточка с информацией о навыках, учебных проектах, любимых инструментах и формой обратной связи.

## Особенности проекта
- **Боковая панель**: блок с любимыми инструментами разработки — Visual Studio Code, PyCharm и CLion.
- **Форма обратной связи**: поля для ввода имени, email и сообщения.
- **Интерактивные состояния**: реализованы `:hover`, `:active`, `:focus` и `:visited`.
- **Позиционирование**: использованы `static`, `relative` и `absolute`.
- **Анимация карточек**: при наведении карточка плавно увеличивается и получает мягкую тень.
- **Бейдж «Top skill»**: декоративный элемент, размещённый в правом верхнем углу карточки.
- **Список проектов**: нумерованный список учебных проектов.
- **Изолированные ресурсы**: изображение хранится в отдельной папке `images/`.
- **Сине-белая цветовая гамма**: оформление страницы с использованием CSS3 и CSS-переменных.
- **Карточки навыков**: навыки Python, C++ и SQL представлены в виде интерактивных карточек.
